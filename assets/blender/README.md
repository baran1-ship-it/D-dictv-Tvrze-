První zkušební model z Blenderu 3.6.23. Úsek 3 × 2,4 metru, 64 samostatných kamenů. Upravitelný .blend obsahuje zabalenou fotografovanou texturu Rock Face 03 (Poly Haven, CC0, Dario Barresi a Rico Cilliers), https://polyhaven.com/a/rock_face_03. Náhled je render Blender Cycles, nikoliv snímek z Android hry. Předmětem hodnocení je přední plocha; bok, koruna zdi, herní materiál a optimalizace jsou rozpracované. Tento díl zatím není vložen do APK.
